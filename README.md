# Saudi Home Services

A home-maintenance marketplace for Saudi Arabia. This repository currently contains UI/UX scaffolding only:

- `apps/customer_app` - Customer Flutter app
- `apps/worker_app` - Worker / service provider Flutter app
- `apps/admin_web` - Next.js admin portal (TypeScript, App Router)
- `packages/design_system` - Shared design system (placeholder)
- `docs/ui-ux` - UI/UX documentation

Planned design direction: English + Arabic (full RTL), Archivo / Tajawal typography.
